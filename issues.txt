Review complete — there are several critical gaps that make the pipeline non-functional end-to-end. Findings are ordered by severity.

**Findings**
- Critical: Uploads never trigger processing — both ingestion endpoints stop at TODOs and `process_rfq_pipeline` is not registered as a Celery task, so RFQs never advance beyond “received.” ingestion.py ingestion.py pipeline_tasks.py
- Critical: Orchestrator templates reference nonexistent outputs (`step2.output.entities` and `{{steps1-5.merged}}`), so any executor will fail to resolve inputs. orchestrator.py orchestrator.py rfq.py
- Critical: NERAgent crashes when ChromaDB is missing because `self.chroma` can be `None` but `retrieve_steel_context` still calls `self.chroma.query`. ner_agent.py ner_agent.py ner_agent.py
- Critical: Groq mock mode is broken — `call()`/`call_async()` access `self.key_rotator` even when no keys exist, so mock-only runs crash before the mock path. groq_client.py groq_client.py
- High: Vision calls are stubbed (`pass`) in non-mock mode, so OCR in production returns `None` and fails. groq_client.py groq_client.py
- High: PricingAgent awaits a synchronous `SerperClient.search`, which will raise “object is not awaitable.” pricing_agent.py serper_client.py
- High: Quote filename mismatch — PDF is saved using `quote_number` but download endpoint expects `QT-{rfq_id}.pdf`, so downloads 404. quote_agent.py quotes.py
- High: WhatsApp `media_url` uses a local file path, not a public URL, so Twilio will fail to attach media. communication_agent.py
- Medium: OCR post-processing replaces every `0` with `O`, corrupting numeric dimensions/quantities (e.g., 10mm → 1Omm). ocr_agent.py
- Medium: Upload path uses raw `file.filename` and doesn’t ensure the storage directory exists; this is path-traversal risk and can crash when `storage/` is missing. ingestion.py ingestion.py
- Medium: RFQ endpoints are stubs with placeholder responses, so status/feed never reflect real data. rfq.py rfq.py rfq.py
- Medium: Quote template expects `margin_percent`, but `QuoteContext` doesn’t provide it. quote_template.html rfq.py
- Low: Frontend uses mock RFQs and a simulated upload; UI is disconnected from the backend. Dashboard.jsx Upload.jsx
- Low: RFQ detail mock total is mathematically wrong (GST applied only to logistics). RFQDetail.jsx
- Low: Reject button text is invisible due to matching background/text color. RFQDetail.css
- Low: Tests target `/api/v1/rfq/upload`, which only exists in the unused mock API module, not in the app router. test_api.py test_api.py mock_api.py main.py
